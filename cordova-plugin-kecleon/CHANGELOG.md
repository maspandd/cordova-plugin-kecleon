# Changelog

## 0.1.0 (2026-10-15)

- First version, Android only: `enable`, `disable`, `isEnabled`, `isCaptured`, `getCapabilities`, and the `screenshot` and `captureChange` events.
- `FLAG_SECURE`, a screenshot callback (API 34+), and a screen-recording callback (API 35+).
- Supports `cordova-android` 14 and later, so the plugin builds on OutSystems MABS 12 (Cordova Android 14) as well as MABS 13.
